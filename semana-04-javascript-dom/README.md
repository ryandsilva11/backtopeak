# ⚡ Semana 04: JavaScript Moderno, DOM & Assincronismo

Bem-vindo à Semana 04! Aqui o seu Front-end ganha cérebro: vamos conectar a página que criamos na Semana 3 a uma API real, gerando os cards de heróis dinamicamente através do JavaScript.

---

## 🎯 Conceitos Chave a Dominar:

- [ ] **Variáveis e Funções:** `const`, `let` e Arrow Functions (`() => {}`).
- [ ] **Manipulação do DOM:** `document.querySelector` e `innerHTML`.
- [ ] **Eventos do Navegador:** `addEventListener('click', ...)`.
- [ ] **Consumo de APIs Assíncronas:** `fetch()` com `async / await`.
- [ ] **Métodos de Array:** `.forEach()` e `.map()` para iterar sobre listas de dados da API.
